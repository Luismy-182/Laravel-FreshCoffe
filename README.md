# Fresh Coffee - Backend

API para la gestión de pedidos de un quiosco de comida.

## 🐘 Tecnologías
- Laravel
- MySQL
- Eloquent ORM

## 🔐 Funcionalidades
- Autenticación de usuarios
- Gestión de pedidos
- Panel administrativo
- Control de acceso por roles

## 🔗 Frontend 
- https://github.com/Luismy-182/fresh-coffee-frontend

## ⚙️ Instalación
```bash
- git clone https://github.com/Luismy-182/fresh-coffee-backend.git
- composer install
- cp .env.example .env
- php artisan key:generate
- php artisan migrate
- php artisan serve
